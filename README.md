# Платформа контроля отдела продаж

Локальная MVP-платформа для контроля проектов, документов и работы отдела продаж.

## Карманный РОП

Вкладка загружает сделки и сотрудников из EnvyCRM через документированный Open API:

- список сделок за выбранный период и фильтр по ответственному;
- этап, дата создания, ответственный и заполненные поля сделки;
- количество проверенных и ожидающих проверки сделок;
- профессиональный аудит записи звонка: доказательная оценка этапов, потребности и критериев клиента, возражений, ошибок, решения по сделке и плана действий;
- стратегия дальнейшего общения с готовым сценарием следующего контакта либо обоснованное подтверждение отказа;
- результат и конкретная рекомендация для каждой сделки;
- сохранение результата проверки в локальной базе SQLite платформы.

Проверка запускается вручную и собирает все доступные доказательства:

1. Карточка сделки: этап, ответственный, заполненные бизнес-поля и пробелы карточки.
2. История CRM: звонки, сообщения, email, задачи и вложения; текст переписки/email передается в AI только после редактирования телефонов, email и ссылок.
3. Если найдена запись звонка, она скачивается во временную папку и распознается локальным `faster-whisper`; стенограмма сохраняется в SQLite до анализа. При отсутствии записи анализ карточки и коммуникаций не блокируется.
4. В CLODEX отправляются только безопасная карточка, очищенная история и стенограмма (если доступна). Отчет содержит доказательства, пробелы карточки, сводку коммуникаций, статус и план действий.

Обещание перезвонить или отправить КП не считается доказательством выполнения.

Установите локальный движок тем же Python, которым запускаете сервер:

```powershell
python -m pip install "faster-whisper==1.2.1" "av>=11,<19"
```

Для `faster-whisper 1.2.1` ограничена версия PyAV: с `av 19.0.0` декодирование падает с `TypeError: open() got an unexpected keyword argument 'metadata_errors'`. На этой машине проверена связка с `av 18.1.0`: синтетическая русская запись WAV длительностью 86 секунд распознана моделью `base` на CPU; сохранение в тестовую SQLite и повторное чтение без распознавания прошли успешно. Это не заменяет проверку реального звонка и API CLODEX.

Первый запуск требует интернета для загрузки модели и может быть долгим. Локальное распознавание не оплачивается по API, но использует ресурсы компьютера. Укажите `LOCAL_WHISPER_MODEL=base` или `small` в локальном `.env`. Если там уже задана дорогая текстовая модель, замените `AI_MODEL` на `gpt-6-sol` (либо выберите её в настройках интерфейса).

Только при отсутствии `faster-whisper` используется внешний Whisper API: задайте отдельно `TRANSCRIPTION_BASE_URL=https://api.openai.com/v1` (или совместимый сервис) и `TRANSCRIPTION_API_KEY`. Запрос идёт на `/v1/audio/transcriptions`, модель `whisper-1`, формат `verbose_json`. Это платный внешний путь: аудио покидает компьютер. Поддержка Whisper в CLODEX не предполагается; без настроенного fallback сервер сообщает ошибку. Ошибка установленного локального движка не приводит к скрытой платной отправке.

Поддерживаются MP3, WAV, OGG, FLAC и M4A до 20 МБ; запись должна иметь подтвержденную положительную длительность. Короткие записи тоже передаются в распознавание, но AI отдельно отмечает ограниченность фактов. Без записи выполняется аудит карточки и доступных коммуникаций, но голосовой аудит недоступен. В карточке доступно «Показать стенограмму». Комментарий отправляется в CRM только явным нажатием соответствующей кнопки. Стенограмма может содержать персональные данные; база SQLite хранит её открытым текстом, а CLODEX получает её при анализе.

## Запуск

1. Установите Python 3.10 или новее.
2. Локальный `.env` уже создан и настроен на CRM и модель из приложения-аудита. Если файла нет, скопируйте `.env.example` в `.env` и укажите свой CRM API-ключ.
3. Добавьте личный API-ключ CLODEX в настройках интерфейса или в `AI_API_KEY`. Ключ хранится только локально на сервере.

```dotenv
AI_BASE_URL=https://clodex.xyz/v1
AI_MODEL=gpt-6-sol
AI_API_KEY=ваш_личный_ключ_clodex
```

Не помещайте API-ключ в HTML/JavaScript, Git или сообщения. Форма «Настройки CLODEX» передаёт ключ серверу и не показывает его обратно. Разрешён только домен `clodex.xyz`.

## КонкурентСкан Pro

Раздел «КонкурентСкан Pro» содержит карточки конкурентов, сайт, канал коммуникации, заметки и загрузку материалов. После нажатия «Запустить AI-анализ» текстовые данные и имена прикрепленных материалов отправляются в CLODEX, а результаты сохраняются локально в браузере для последующего сравнения. Бинарное содержимое файлов пока не загружается в AI.

4. Запустите `start-server.bat` из папки проекта и оставьте его окно открытым.
   Существующий `run.bat` запускает coding-агент, а не сервер платформы.
   Либо выполните из папки проекта:

```bash
python server.py
```

5. Откройте `http://127.0.0.1:8000`.
6. Войдите в систему, откройте «Карманный РОП» и нажмите «Обновить сделки».

Ключ CRM, переданный владелицей платформы, сохранён только в локальном `.env`, который исключён из Git. Анализ не заработает до настройки `AI_API_KEY`. Результаты аудита сохраняются локально, а не в CRM.

## Примечания

- Для записей Telphin обнаружен прямой GET-маршрут `https://<домен CRM>/api/callrecords/telphin/<ID записи>`, возвращающий `audio/mpeg`. Проверенная запись доступна без cookies и API-ключа; сервер не добавляет CRM-ключ к этому маршруту. Ссылки распознаются и без расширения файла, включая JSON-данные истории. Доступность остальных записей и наличие ссылки в Open API требуют отдельной проверки. Не публикуйте ссылки на записи: они могут предоставлять доступ без авторизации.
- Проверка обработки ссылок: `python -m unittest test_recordings -v` из каталога проекта.

- `.env` и локальная база `pocket-reviews.sqlite3` исключены из Git.
- Сервер по умолчанию слушает только `127.0.0.1`. Для сетевого развёртывания потребуется настроить защищённую аутентификацию и HTTPS.
- Пароли ролей в интерфейсе пока демонстрационные и не являются защитой для публичного развёртывания.


## Extension deployment

This repository contains the EnvyCRM-connected Pocket ROP. GitHub Pages can host the interface only; real CRM data requires running `server.py` behind a public HTTPS endpoint. Do not put CRM or AI keys into GitHub Pages or browser code.
